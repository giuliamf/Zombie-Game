## Descrição do Projeto

Esta quinta entrega expande o projeto com a implementação de um sistema completo de combate, incluindo personagem jogável, arma com sistema de tiro, projéteis com física e detecção de colisões. O projeto mantém a arquitetura baseada em composição e adiciona mecânicas de gameplay interativo.

O programa exibe uma janela de 1200x900 pixels com música de fundo, plano de fundo, mapa baseado em TileMap, um personagem controlável pelo jogador, uma arma que segue o mouse e múltiplos inimigos (zombies) que podem ser eliminados através de tiros. O sistema de colisão detecta quando projéteis atingem inimigos, executando animações de morte antes de remover as entidades do jogo.

## Arquitetura e Principais Classes

### Evolução da Arquitetura

A Entrega 5 mantém a arquitetura baseada em composição e adiciona sistemas de gameplay interativo. O projeto agora possui um loop completo de combate: entrada do jogador → movimentação → mira → disparo → colisão → eliminação de inimigos.

### Character

A classe [`Character`](include/Character.h) representa o personagem jogável.

**Responsabilidades:**
- Gerenciar velocidade e movimentação do personagem
- Criar e gerenciar a arma associada ao personagem
- Controlar pontos de vida (hp)
- Fornecer interface para controle de velocidade

**Métodos principais:**
- [`Character::Start()`](src/Character.cpp:16): Cria o GameObject da arma e o adiciona ao State
- [`Character::Update()`](src/Character.cpp:54): Atualiza a posição baseada na velocidade
- [`Character::SetSpeed()`](src/Character.cpp:63): Define a velocidade de movimentação

**Detalhes de implementação:**
- A arma é criada dinamicamente no `Start()` e adicionada ao State
- Mantém referência `weak_ptr` para a arma criada
- Velocidade linear configurável (800 pixels/segundo para testes)

### PlayerController

A classe [`PlayerController`](include/PlayerController.h) traduz entrada do teclado em comandos de movimentação.

**Responsabilidades:**
- Capturar entrada do teclado (WASD)
- Calcular direção de movimento normalizada
- Atualizar velocidade do Character associado

**Métodos principais:**
- [`PlayerController::Update()`](src/PlayerController.cpp:14): Processa input e atualiza velocidade

**Controles:**
- **W** → mover para cima
- **S** → mover para baixo
- **A** → mover para esquerda
- **D** → mover para direita

### Gun

A classe [`Gun`](include/Gun.h) representa a arma do personagem.

**Responsabilidades:**
- Seguir a posição do personagem
- Rotacionar em direção ao cursor do mouse
- Criar projéteis ao clicar
- Controlar taxa de disparo (cooldown)

**Atributos principais:**
- `character`: Referência `weak_ptr` ao personagem
- `angle`: Ângulo atual da arma
- `cooldownTimer`: Timer para controle de taxa de disparo
- `cooldownTime`: Intervalo mínimo entre disparos

**Métodos principais:**
- [`Gun::Update()`](src/Gun.cpp:28): Atualiza posição, rotação e disparo
- [`Gun::Start()`](src/Gun.cpp:18): Inicializa o sprite da arma

**Mecânica de disparo:**
- Cooldown de 0.5 segundos entre tiros
- Projéteis criados na posição da arma
- Direção baseada no ângulo para o mouse

### Bullet

A classe [`Bullet`](include/Bullet.h) representa um projétil disparado.

**Responsabilidades:**
- Movimentar-se em linha reta
- Detectar colisões com inimigos
- Autodestruir-se após distância máxima
- Notificar inimigos atingidos

**Atributos principais:**
- `speedVec`: Vetor de velocidade (direção × velocidade)
- `distanceLeft`: Distância restante antes de desaparecer

**Métodos principais:**
- [`Bullet::Update()`](src/Bullet.cpp:25): Move o projétil e verifica colisões
- Parâmetros configuráveis: velocidade (1500 px/s) e distância máxima (800 px)

**Detecção de colisão:**
- Itera sobre todos os GameObjects do State
- Verifica se possui componente Zombie
- Usa [`Collision::IsColliding()`](src/Collision.cpp:3) para detectar sobreposição
- Notifica o zombie através de `NotifyHit()`

### Collision

A classe [`Collision`](include/Collision.h) fornece detecção de colisão AABB (Axis-Aligned Bounding Box).

**Responsabilidades:**
- Detectar sobreposição entre retângulos
- Fornecer método estático para verificação de colisão

**Método principal:**
- [`Collision::IsColliding()`](src/Collision.cpp:3): Verifica se dois `Rect` se sobrepõem

**Algoritmo:**
```cpp
// Verifica separação nos eixos X e Y
if (a.pos.x + a.size.x < b.pos.x) return false;  // A está à esquerda de B
if (b.pos.x + b.size.x < a.pos.x) return false;  // B está à esquerda de A
if (a.pos.y + a.size.y < b.pos.y) return false;  // A está acima de B
if (b.pos.y + b.size.y < a.pos.y) return false;  // B está acima de A
return true;  // Há sobreposição
```

### Zombie (Atualizado)

A classe [`Zombie`](include/Zombie.h) foi expandida para suportar morte por projétil.

**Novas funcionalidades:**
- Método [`Zombie::NotifyHit()`](src/Zombie.cpp:88): Chamado quando atingido por projétil
- Animação de morte com delay de 2 segundos antes de remover do jogo
- Flag `isDead` para prevenir múltiplos hits

**Comportamento de morte:**
1. Projétil colide e chama `NotifyHit()`
2. Zombie para animação e muda para frame de morte
3. Permanece visível por 2 segundos
4. GameObject é marcado para remoção com `RequestDelete()`

### State (Atualizado)

A classe [`State`](include/State.h) foi expandida com funcionalidades para múltiplos inimigos.

**Novas funcionalidades:**
- Método [`State::CreateZombie()`](src/State.cpp:115): Factory method para criar zombies
- Método [`State::GetObjectArray()`](src/State.cpp:209): Acesso ao array de objetos para detecção de colisão
- Criação de 5 zombies em posições estratégicas ao redor do jogador

**Posições dos zombies:**
- Enemy 1: (1800, 1300) - À direita
- Enemy 2: (1280, 900) - Acima
- Enemy 3: (800, 1300) - À esquerda
- Enemy 4: (1500, 1600) - Abaixo-direita
- Enemy 5: (1000, 1000) - Diagonal superior-esquerda

### GameObject (Atualizado)

A classe [`GameObject`](include/GameObject.h) foi expandida com sistema de remoção.

**Novas funcionalidades:**
- Método [`GameObject::RequestDelete()`](src/GameObject.cpp:48): Marca objeto para remoção
- Método [`GameObject::IsDead()`](src/GameObject.cpp:52): Verifica se objeto deve ser removido
- Atributo `isDead`: Flag de remoção

**Fluxo de remoção:**
1. Componente chama `associated.RequestDelete()`
2. GameObject marca `isDead = true`
3. State remove objetos mortos no `Update()` usando `std::remove_if`

### InputManager (Atualizado)

A classe [`InputManager`](include/InputManager.h) foi expandida com suporte a mouse.

**Novas funcionalidades:**
- [`InputManager::IsMouseDown()`](src/InputManager.cpp:46): Verifica se botão do mouse está pressionado
- [`InputManager::GetMouseX()`](src/InputManager.cpp:67) e [`GetMouseY()`](src/InputManager.cpp:71): Posição do cursor
- Arrays `mouseState` e `mouseUpdate` para gerenciar estado dos botões

## Fluxo de Gameplay

### Loop de Combate

```
1. Jogador pressiona WASD
   ↓
2. PlayerController atualiza velocidade do Character
   ↓
3. Character move o GameObject
   ↓
4. Câmera segue o Character
   ↓
5. Gun segue o Character e rotaciona para o mouse
   ↓
6. Jogador clica com o mouse
   ↓
7. Gun cria Bullet (se cooldown permitir)
   ↓
8. Bullet se move e verifica colisões
   ↓
9. Se colidir com Zombie:
   - Zombie::NotifyHit() é chamado
   - Zombie muda para frame de morte
   - Bullet é destruído
   ↓
10. Após 2 segundos, Zombie é removido do jogo
```

### Controles

**Movimentação:**
- **W** → mover para cima
- **S** → mover para baixo
- **A** → mover para esquerda
- **D** → mover para direita

**Combate:**
- **Mouse** → mirar
- **Botão esquerdo do mouse** → atirar

**Debug:**
- **ESPAÇO** → eliminar zombie imediatamente (mantido da entrega anterior)

## Como Compilar e Executar

### Pré-requisitos

Certifique-se de ter instalado:
- Xcode Command Line Tools
- SDL2, SDL2_image e SDL2_mixer via Homebrew

```bash
brew install sdl2 sdl2_image sdl2_mixer
```

### Compilação

No terminal, navegue até o diretório do projeto e execute:

```bash
clang++ src/*.cpp \
-Iinclude \
-I/opt/homebrew/include \
-L/opt/homebrew/lib \
-lSDL2 -lSDL2_image -lSDL2_mixer \
-std=c++17 \
-o jogo
```

### Execução

Após a compilação, execute:

```bash
./jogo
```

A aplicação abrirá uma janela de 1200x900 pixels exibindo:
- Plano de fundo
- Mapa baseado em TileMap
- Personagem controlável
- Arma que segue o mouse
- 5 zombies espalhados pelo cenário
- Música ambiente

### Gameplay

1. Use **WASD** para mover o personagem
2. Mova o **mouse** para mirar
3. Clique com o **botão esquerdo** para atirar
4. Elimine todos os zombies!
